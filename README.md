# BP Parser for SVTR - Chrome Extension

从 Business Plan (PDF/文字) 自动提取信息，填写 SVTR 飞书入驻申请表单。

## 安装方法

1. 打开 Chrome，访问 `chrome://extensions/`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择 `bp-parser-extension/` 文件夹
5. 扩展安装完成，工具栏会出现 BP 图标

> **图标说明**：`icons/` 文件夹内需要 `icon16.png`、`icon48.png`、`icon128.png`。
> 可用任意图片工具创建，或暂时用同一张图复制三份重命名。

## 使用流程

1. **输入 API Key**
   点击扩展图标 → 输入 Claude API Key（`sk-ant-...`）→ 点击保存

2. **上传 BP**
   选择 PDF 文件，或切换到"文字内容"标签粘贴文字

3. **解析**
   点击「解析 BP 内容」，Claude 会提取以下字段：
   - 身份类型、姓名、工作单位、当前职务
   - 所需服务（复选）、公司邮箱

   > 微信号、如何找到我们、是否是会员 通常 BP 中没有，需手动填写

4. **检查并编辑**
   提取结果可直接在弹窗中修改

5. **填写表单**
   在浏览器中打开 SVTR 飞书申请表单 → 点击「填写飞书表单」→ 自动填写 → 人工检查后提交

## 表单字段映射

| # | 字段 | 类型 | 来源 |
|---|------|------|------|
| 1 | 身份类型 | 单选 | Claude 推断 |
| 2 | 姓名 | 文本 | BP 提取 |
| 3 | 工作单位 | 文本 | BP 提取 |
| 4 | 当前职务 | 文本 | BP 提取 |
| 5 | 个人微信 | 文本 | 手动填写 |
| 6 | 所需服务 | 多选 | Claude 推断 |
| 7 | 公司邮箱 | 文本 | BP 提取 |
| 8 | 补充材料 | 文件 | 手动上传 |
| 9 | 如何找到我们 | 单选 | 手动选择 |
| 10 | 是否是SVTR会员 | 单选 | 手动选择 |

## 注意事项

- 表单填写后**不会自动提交**，需人工确认后点击提交
- 如果飞书表单更新了 UI 结构，`content.js` 中的选择器可能需要调整
- API Key 保存在本地 Chrome 存储中，不会上传到任何服务器

## 文件结构

```
bp-parser-extension/
├── manifest.json    # Extension 配置
├── popup.html       # 弹窗 UI
├── popup.css        # 样式
├── popup.js         # 弹窗逻辑
├── background.js    # Claude API 调用 (Service Worker)
├── content.js       # 注入飞书页面，填写表单
└── icons/           # 扩展图标
```
